# تطوير الويب باستخدام نموذج MVC في لغة جافا

يحتوي هذا المستودع على موارد وتمارين مصممة لمساعدتك على تعلم أساسيات تطوير الويب في لغة جافا، باستخدام **السرفلت** و**صفحات JSP**.

> [!نصيحة]
> **ادخل إلى الدورة التدريبية الكاملة:** [https://stahe.github.io/ar-java-web-mvc-mai-2006/](https://stahe.github.io/it-java-web-mvc-mai-2006/)

---

## 📖 مقدمة

الغرض من هذا المورد هو تناول المفاهيم الأساسية للبرمجة على الويب بلغة Java من خلال بنية **MVC ذات 3 مستويات**. يستند هذا المستند إلى المقالة المنشورة في يناير 2005 بعنوان "تطوير الويب بلغة Java باستخدام Eclipse وTomcat"، مع إضافة:
* استخدام المكون الإضافي **Eclipse WTP**.


* بنية تستند إلى **الهندسة ذات المستويات الثلاثة**.


* مثال عملي يستخدم **نظام إدارة قواعد البيانات**.




## 🏗️ هندسة التطبيق

يتبع المشروع بنية ذات ثلاثة مستويات لضمان نمطية واستقرار الكود:

**المستوى الويب [web]** | واجهة تسمح للمستخدم بالتحكم في التطبيق وتلقي المعلومات.

**المستوى التجاري [business]** | يحتوي على المنطق التجاري. وهو مستقل عن الواجهة (الويب، وحدة التحكم، إلخ)، وهو المستوى الأكثر استقرارًا.

**مستوى الوصول إلى البيانات [DAO]** | يدير الوصول إلى البيانات الدائمة (DBMS) أو البيانات الخارجية (أجهزة الاستشعار، الشبكة).


## 🚀 طرق التعلم

هناك عدة طرق ممكنة لتعلم هذا المحتوى، تتراوح من الأسرع إلى الأكثر فعالية:

1. **النهج المخصص للخبراء:** قم بتثبيت الأدوات وجرب الكود الذي تم تنزيله مباشرةً (فقط للمطورين الملمين بـ Eclipse/WTP).


2. **النهج السريع:** انسخ الكود والصقه باتباع الوثيقة. يتيح لك التقدم بسرعة، لكن بعض المفاهيم قد تظل "غامضة".


3. **النهج الموجه:** مطابق للطريقة 2، ولكن راجع الوثيقة المرجعية `[ref1]` (مقدمة في برمجة الويب بلغة Java) كلما تم التوصية بذلك.


4. **النهج الموصى به:** اكتب الكود بالكامل يدويًا مع القراءة بعناية. هذه هي الطريقة الأكثر فعالية لفهم المنطق وتصحيح أخطاءك النحوية.
